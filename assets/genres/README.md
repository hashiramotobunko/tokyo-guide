# Illustrated genre filters

These 32 WebP files were retrieved from the owner-provided Box folder `437537990018` on 2026-11-18 and are used as interactive genre filters in `tokyo-guide_2.html`.

- Source dimensions: 960 × 1200 pixels
- Format: WebP
- Display role: original interpretive illustrations, not photographs of listed venues
- Accessibility: the images are decorative inside buttons whose accessible names contain the exact data category, current-region result count and region name
- Performance: images use native lazy loading and fixed dimensions to avoid loading every full-size illustration before it is needed or shifting the layout

The category-to-file mapping lives in `EJ_GENRE_ART`. It deliberately uses the exact category strings already present in the immutable 526-place dataset; it does not alter listing names, order, regions, Google Maps links or routes.
